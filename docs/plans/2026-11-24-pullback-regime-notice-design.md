# 回檔訊號暫停時說明原因：設計

2026-11-24。

## 為什麼要做

使用者發現今日頁「回檔觀察」很多天都沒有股票，懷疑是壞掉了。實際上是設計使然：四條回檔主訊號（強勢回檔到 MA20、強勢回檔到 MA10、支撐錘子、KD 高檔回落）共用的 `pullbackPrologue` 有一道大盤閘門，`AnalysisContext.isMarketUptrend == false` 時全部不觸發。

這道閘門判斷的是：當天評分的候選股中，120 個交易日的報酬取中位數，大於 0 才算多頭。過半候選股比半年前高時，中位數一定大於 0；但檔數是偶數、剛好一半比半年前高時，中位數取兩個中間值的平均，正負要看兩者的幅度（`price_calculator.dart` 的 `marketUptrendOrNull` 註解），所以剛好一半也可能判成多頭。設計理由是 2026-07-10 的回放：空頭時的回檔，60 日平均報酬只有 −0.7%～+1.3%，多頭時是 +6.5%。

本機資料庫量到的數字：

| 日期 | 候選股比半年前高 | 中位數 | 判定 | 四條回檔訊號觸發檔數 |
|:--|--:|--:|:--|--:|
| 11/02 | 55%（294／537） | +3.94% | 多頭 | 15 |
| 11/03 | 48%（289／596） | −0.94% | 非多頭 | 0 |
| 11/24 | 29%（132／455） | −16.09% | 非多頭 | 0 |

11/03～11/24 共 16 個交易日都是 0 檔；在那之前每天 5～40 檔。10/20 以來沒有任何程式改動碰到判定、候選池或回檔規則。

但畫面上沒有任何線索：
- 今日頁的空白狀態寫「今日無訊號・目前沒有符合條件的股票，請稍後再試或手動更新」，還附一個「更新」按鈕，暗示重新整理就會有。
- 新聞熱度頁勾「只看回檔中」後，清單直接空白，一個字都沒有。

以現在 29% 的水位，這種狀態可能持續好幾週。

## 目標

- 判定為非多頭時，在上面兩處寫明「回檔訊號因大盤偏空而暫停」，並說出現在的數字和恢復條件。
- 畫面上的說明和評分當天實際用的判定是同一份資料，不會說錯原因。

## 不做的事

- 不改閘門本身：門檻、回看天數、候選池都不動。
- 不在分頁按鈕上標「暫停」：使用者選 A，只在空白處說明。
- 不動起漲候選、強勢觀察：它們沒有這道大盤閘門。
- 不補算過去的日期：上線前的日子沒有存判定，照舊顯示一般的空白訊息。
- 不改回放工具（`tool/replay_calibrator.dart` 的 `computeMarketUptrendByDate`）。

## 反目標（做了也算失敗的情況）

- 多頭但剛好沒有股票符合時，顯示「大盤偏空」。
- 畫面說明用的日期，和推薦清單用的分析日期不同天。
- 為了顯示說明，在畫面上另算一套判定，和評分時的結果對不上。

## 做法的比較

1. **評分時把判定存起來，畫面讀它**（採用）。說明和評分用的是同一個數字，不會說錯原因。代價是新增一張表，評分的兩條路徑都要把判定帶回來。
2. 畫面自己再算一次：要載入幾百檔、各 120 天以上的價格，而且候選池的範圍要和評分時完全一致才不會分岔。這個專案已經有一處同一語意寫了兩份實作（回放工具），要靠 parity 測試守，不再多一份。
3. 從「今天沒有任何回檔訊號」反推是大盤的關係：多頭時偶爾也會 0 檔，會說錯原因。

## 設計

### 1. 判定的計算多回傳幾個數字

在 `PriceCalculator` 新增一個回傳讀數的版本，例如 `marketRegimeReading(...)`，回傳：
- 有效股數
- 比半年前高的檔數（報酬 > 0）
- 中位數報酬
- 是否多頭（中位數 > 0）

有效股不足 `SectorParams.regimeMinEligibleStocks` 時回 null。

`marketUptrendOrNull` 改成讀它的「是否多頭」，行為完全不變：仍用 `median()`，有效股的認定與 `asOf` 過濾都不變。現有的 `replay_production_parity_test` 必須照樣通過。

### 2. 評分兩條路徑都把讀數帶回來

- **背景路徑**：`evaluateStocksIsolated` 已經在算判定。改成算讀數，規則判斷用其中的「是否多頭」，讀數放進 `ScoringBatchResult` 帶回主 isolate。讀數型別只含整數、浮點數、布林，可以跨 isolate。讀數是在 isolate 裡算出、隨結果傳回的（不在輸入裡），所以跨界測試放在 `scoring_market_regime_test`：真的 spawn isolate，輸入 60 檔，讀數非 null 地傳回。
- **主執行緒備援路徑**：`ScoringService.scoreStocks` 同樣算讀數、用同一個值。

兩條路徑對同一份輸入要得到相同的讀數，要有測試斷言。

### 3. 存進資料庫

- 新表 `market_regime`，每個評分日一列。欄位：
  - `date`：主鍵，與 `daily_analysis.date` 同樣正規化
  - `eligible_count`、`up_count`：整數
  - `median_return`：實數
  - `is_uptrend`：布林
  - `lookback_days`：整數，記下當時用的回看天數
- 建表沿用 `_ensure*Schema()` 的冪等寫法（`Migrator.createTable`），不升 `schemaVersion`、不升 schema 指紋，也不加進 `_userInputTableNames`（它是衍生資料，重設時要一起清）。
- 寫入放在評分「清掉當天分析、寫入新分析」的同一個 transaction 裡：先刪當天那一列；讀數不是 null 才寫入新的。兩條評分路徑都要寫。
- 由誰提供讀寫方法由實作者決定，可以用既有的 analysis repository／DAO 或新 DAO，但要能在那個 transaction 裡呼叫。

### 4. 畫面讀取

- 讀取放在推薦清單的 provider（`_modeAssignmentsProvider`）裡，用它已經取得的分析日期（`findLatestAnalysisDate()` 的結果）讀同一天的讀數，跟推薦結果一起提供。今日頁和新聞熱度頁兩個畫面都從這裡拿，日期就一定一致。
- 對外提供「回檔暫停」的資訊：只在讀數存在、而且不是多頭時給值（帶比例），其餘都是 null。null 包括多頭、沒有讀數、沒有分析日期。
- 跟著推薦清單一起重新整理（`dataUpdateEpochProvider`），不另外訂閱。

### 5. 今日頁「回檔觀察」空白狀態

- 回檔暫停時：
  - 標題：「大盤偏空，回檔訊號暫停」
  - 說明：「今天評分的股票只有 {pct}% 比半年前高，過半就會恢復。大盤偏空時，回檔之後的表現明顯較差。」
  - 不放「更新」按鈕
- 其他情況：維持現在的「今日無訊號」。
- 只影響回檔觀察分頁；另外兩個分頁不變。
- `{pct}` ＝ 比半年前高的檔數 ÷ 有效股數 × 100，**無條件捨去**到整數，避免 49.6% 顯示成「50%」。暫停時比例一定不超過 50%。
- 寫「過半就會恢復」，不寫「要過半才會恢復」：過半一定恢復；剛好一半時也可能恢復（見「為什麼要做」），「要過半」會說得太死。

### 6. 新聞熱度頁「只看回檔中」

勾選後篩出來是空的：
- 回檔暫停時：顯示同一段標題與說明（精簡版）。
- 其他情況：顯示「焦點個股中目前沒有回檔中的股票」。（現在是什麼都不寫；這是我的決定：同一個畫面、同一種困惑，順手補上。）

### 7. 文字

- 中文、英文翻譯都要有。
- 必須通過 `no_investment_advice_copy_test`：禁用字包括「推薦」「進場」「買點」「機會」「有利」「值得」「接刀」等，英文另有禁用的詞。上面的文字已避開。
- 「今天評分的股票」指判定所用的候選池。App 的文字沒有用過「候選股」，所以不用這個詞。

## 邊界情況

- 有效股不足 50：判定是 null（閘門不擋），不存讀數，顯示一般空白訊息。
- 上線後第一次評分之前，最近分析日沒有讀數：顯示一般空白訊息。
- 同一天重新評分：transaction 內先刪後寫，讀數換成新的；新的讀數是 null 時，那天就沒有讀數。
- 判定為非多頭時，回檔觀察一定是空的（四條主訊號都被擋下），所以說明只出現在空白狀態，不會和有股票的清單同時出現。

## 測試

- 判定讀數的計數、比例、中位數；`marketUptrendOrNull` 行為不變；replay parity 測試照過。不能把「多頭 ＝ 上漲檔數 × 2 > 有效股數」當成必然成立的條件來斷言；偶數檔剛好一半的兩種情況（中位數 > 0、≤ 0）各放一個測試。
- 背景路徑與主執行緒路徑對同一份輸入得到相同讀數；真的 spawn isolate，讓非 null 的讀數跨界傳回（輸入要有至少 50 檔、在評分日有 121 根以上 K 棒的股票）。
- 評分寫入：多頭、非多頭都寫一列；讀數是 null 時不寫；同一天重新評分時會換掉；寫入失敗時連同分析一起回滾。
- 新表的冪等補建：既有資料庫開啟後有這張表、資料不動。照既有的 migration 測試寫法。
- provider：讀的是推薦清單那一天；多頭、沒有讀數時是 null。
- 畫面：
  - 回檔觀察空白時，非多頭顯示說明、沒有「更新」按鈕；多頭或沒有讀數時，顯示原本的訊息和按鈕。
  - 起漲候選、強勢觀察的空白狀態不受影響。
  - 新聞熱度頁「只看回檔中」為空時的兩種文字。
- 文字守門測試通過；`tool/` 鏈仍是純 Dart（`dart compile kernel tool/daily_update.dart`）。
